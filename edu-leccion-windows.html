Atajos de
Windows

La tecla Windows (⊞) es tu superpoder. Estos atajos te ahorran clicks y te hacen ver pro. Memoriza los top 5 y ya ganas.

⭐ Top 5 — Aprende estos YA

Si solo aprendes 5, que sean estos. Uso diario garantizado.

Win + E
Abrir Explorador de archivos — Al instante. Sin buscar icono, sin Win+R → explorer. El #1 que debes memorizar.
Win + D
Mostrar/ocultar Escritorio — Minimiza todo al instante. Otra vez: restaura. Perfecto para "jefe pasando" o acceder a acceso directo en escritorio.
Win + L
Bloquear sesión — Seguridad instantánea. Te vas a café → Win+L. Vuelves → PIN/huella/face. Hábito obligatorio en oficina.
Win + V
Historial del portapapeles — Actívalo la primera vez (te pide). Guarda últimas 25 copias (texto, imágenes). Pega la de hace 10 min. Cambia la vida.
Win + Shift + S
Captura de pantalla (recorte) — Rectángulo, ventana, pantalla completa, forma libre. Se copia al portapapeles + notificación para anotar. Olvídate de PrtScn + Paint.

⚙️ Sistema y configuración

Win + I
Abrir Configuración — Directo a la app moderna. Más rápido que Inicio → engranaje.
Win + A
Centro de acciones / Configuración rápida — Wi-Fi, Bluetooth, brillo, modo enfoque, proyección, nearby sharing.
Win + X
Menú usuario avanzado (Power User) — Acceso directo: Admin. tareas, Admin. dispositivos, PowerShell, Ejecutar, Apagar, etc. Menú oculto pro.
Ctrl + Shift + Esc
Administrador de tareas directo — Salta Ctrl+Alt+Supr. Abre Admin. tareas al instante. Imprescindible cuando algo se cuelga.
Win + R
Ejecutar — Comandos rápidos: cmd, powershell, msconfig, regedit, control, . (carpeta usuario), shell:startup.
Win + Pausa
Propiedades del sistema (Acerca de) — Ver RAM, CPU, versión Windows, nombre equipo, ID producto. Rápido para specs.

🪟 Gestión de ventanas (Snap / Snapping)

Windows 10/11 tiene el mejor gestor de ventanas nativo. Úsalo.

Win + Flecha Izq / Der
Anclar ventana a la mitad — Izquierda o derecha. Luego Win+Arriba/Abajo = cuadrante (esquina). Base del multitarea serio.
Win + Flecha Arriba / Abajo
Maximizar / Restaurar / Minimizar — Si está a mitad: mueve a cuadrante superior/inferior. Si maximizada: restaura. Si normal: minimiza.
Win + Z
Diseños de ajuste (Snap Layouts) — Windows 11: pasa ratón por botón maximizar o Win+Z → elige layout (2, 3, 4 ventanas).
Win + Tab
Vista de tareas (Timeline) — Ve todas las ventanas abiertas + escritorios virtuales + historial de actividades. Esc para salir.
Win + Ctrl + D
Nuevo escritorio virtual — Separa trabajo / personal / proyectos. Win+Ctrl+Flecha Izq/Der = cambiar. Win+Ctrl+F4 = cerrar actual.
Win + Inicio
Minimizar todo MENOS la activa — Limpia el ruido, foco en lo que haces.
Win + Shift + Flecha Izq/Der
Mover ventana a otro monitor — Multi-monitor: pasa ventana al monitor de al lado al instante.

🔍 Búsqueda y lanzamiento

Win + S / Win + Q
Búsqueda de Windows — Escribe nombre de app, archivo, config, web. Enter = abre. La forma más rápida de lanzar cualquier cosa.
Win + 1 / 2 / 3 ... 9
Abrir app anclada en barra — Por posición (1 = primera a la derecha de Inicio). Win+Shift+1 = nueva instancia.
Win + T
Ciclar apps en barra — Flechas para moverte, Enter para abrir/focus. Sin ratón.

♿ Accesibilidad y extras útiles

Win + + / -
Lupa (Zoom) — Win++ = acerca, Win+- = aleja, Win+Esc = cierra. Ideal para presentar o leer letra chica.
Win + H
Dictado por voz — Habla y escribe. Funciona bien en español. Micrófono + permiso primera vez.
Win + . (punto) / ; (punto y coma)
Panel emojis / kaomojis / símbolos — 🎉 😎 📊 → inserta en cualquier campo de texto.
Win + G
Barra de juegos (Xbox Game Bar) — Grabar pantalla (Win+Alt+R), captura, audio, rendimiento, widgets. No solo para gamers.
Win + Alt + R
Iniciar/parar grabación pantalla — Directo sin abrir Game Bar. Guarda en Capturas/Vídeos.
Win + K
Conectar / Proyectar — Pantalla inalámbrica (Miracast), dock, segunda pantalla. Rápido para presentar.

💡 Combos de poder (flujos reales)

Setup mañana productiva

Win+D (limpiar) → Win+1 (navegador) → Win+Flecha Izq → Win+2 (Outlook/Teams) → Win+Flecha Der → Win+Flecha Arriba (cuadrante sup. der. para notas/To-Do).

Algo se cuelga

Ctrl+Shift+Esc (Admin. tareas) → busca proceso → Supr / Clic derecho → Finalizar. Si todo congelado: Ctrl+Alt+Supr → Admin. tareas.

Captura y comparte

Win+Shift+S (recorte) → anota si quieres → Ctrl+V en WhatsApp/Teams/Email. Listo.

Portapapeles multi-elemento

Copias 3 cosas seguidas (Ctrl+C x3) → Win+V → clic en la que quieras pegar. Funciona entre apps.
