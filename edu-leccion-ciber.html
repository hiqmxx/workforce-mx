No hace falta ser experto. Unos hábitos simples te blindan contra el 95% de ataques. Tu negocio y tu tranquilidad lo valen.

🎯 La regla de oro

La seguridad no es un producto, es un hábito. No compras "seguridad", la construyes con decisiones diarias. Empieza hoy, mejora mañana.

🔐 1. Contraseñas seguras + Gestor

El eslabón más débil. La gente reusa "Empresa2024!" en todo. Si una web filtra esa pass, tienen acceso a todo.

✓
Únicas: Una distinta para cada servicio. Si se filtra una, el resto a salvo.
✓
Largas (16+ chars): Frase aleatoria > complejidad rara. correcto-caballo-bateria-grapa tarda siglos en fuerza bruta; P@ssw0rd! segundos.
✓
Gestor de contraseñas (obligatorio): Bitwarden (gratis, open source), 1Password, KeePassXC. Genera, guarda, autocompleta, sincroniza. Solo recuerdas UNA master pass fuerte.
✓
Revisa filtraciones: haveibeenpwned.com → pon tu email → ve en qué brechas apareces → cambia esas passes YA.

🛡️ 2. Autenticación de dos factores (2FA / MFA)

Tu contraseña puede robarse (phishing, keylogger, filtración). 2FA añade algo que TIENES (teléfono, llave hardware) o algo que ERES (huella, Face ID).

✓
Actívalo en TODO: Email, banca, redes, AWS/Azure, GitHub, gestor de passes, admin de tu web/hosting.
✓
Orden de seguridad: Llave hardware (YubiKey) > App autenticadora (Authy, Google Auth, Microsoft Auth, Bitwarden) > SMS (mejor que nada, pero vulnerable a SIM swapping).
✓
Guarda códigos de respaldo: Al activar 2FA, te dan 8-10 códigos de emergencia. Guárdalos en papel (caja fuerte) o en tu gestor de passes. Si pierdes el 2FA, entras con esos.

🎣 3. Phishing: cómo no caer

El 90%+ de ataques empiezan con un correo/link engañoso. Te suplantan: banco, SAT, Microsoft, Google, tu proveedor, un cliente.

✓
Verifica el remitente REAL: Pasa ratón sobre "De:" → mira el dominio. factura@sat.gob.mx pero dominio sat-gob-mx-facturas.ru = phishing.
✓
Urgencia = señal de alarma: "Tu cuenta se cierra en 24h", "Pago rechazado, actúa ya", "Factura pendiente". Los legitimos no presionan así.
✓
No cliques links en email sospechoso: Entra manual al sitio (escribe URL o usa favorito). Si es de tu banco, abre la app oficial.
✓
Adjuntos .exe, .zip, .scr, .iso, .img, .html: Pueden esconder malware. PDFs pueden tener exploits. Si no lo esperabas, no lo abras. Verifica por otro canal (llama, WhatsApp conocido).
✓
Spear phishing (dirigido): Usan tu nombre, empresa, proyecto real. "Hola Juan, adjunto el brief del proyecto Alfa". Más creíble. Verifica SIEMPRE.

🔄 4. Actualizaciones: el parche gratis

Vulnerabilidades conocidas = puertas abiertas. Los exploits masivos (WannaCry, Log4j, PrintNightmare) atacan sistemas SIN parchear semanas/meses después del fix.

✓
Windows Update: Automático + reinicios programados. No lo pauses semanas.
✓
Navegador (Chrome/Edge/Firefox): Se actualizan solos, pero reinícialos de vez en cuando para aplicar.
✓
Office, Adobe, drivers GPU, BIOS/UEFI, router, NAS, apps móviles: Revisa mensual.
✓
Software EOL (fin de vida): Windows 7/8.1, Office 2013, viejas versiones de PHP/Python/Node. Si no tiene parches, MIGRA. Es un riesgo inaceptable.

💾 5. Copias de seguridad: la red de seguridad

Ransomware cifra tus archivos y pide rescate. Fallo de disco = todo perdido. Robo/incendio = todo perdido. Backup = recuperas.

✓
Regla 3-2-1: 3 copias (original + 2 backups), 2 medios distintos (disco local + nube / 2 discos), 1 fuera de sede (nube / disco en casa de familiar / oficina distinta).
✓
Automatizado: Si depende de que tú lo hagas, fallará. Veeam Agent Free, Macrium Reflect Free, Duplicati, Restic, Backblaze, OneDrive/Google Drive (versionado), Synology Hyper Backup.
✓
Prueba la restauración: Una vez al trimestre, restaura un archivo/carpeta aleatoria. Si no probaste, no tienes backup, tienes esperanza.
✓
Inmutable / versionado: Que el ransomware no pueda cifrar/borrar el backup. Backblaze B2, Wasabi, S3 con Object Lock, discos desconectados (offline) tras backup.

🚪 6. Control de acceso: mínimo privilegio

No des llaves maestras a quien solo necesita entrar a una habitación.

✓
Cuentas de usuario estándar (no admin) para uso diario: Instalar software → pide credenciales admin (UAC). Malware que entra por user estándar no puede tocar sistema.
✓
Accesos por rol: Contabilidad ve contabilidad. Ventas ve CRM. Admin ve todo. Revoca accesos al salir alguien (offboarding inmediato).
✓
VPN / Zero Trust para remoto: No expongas RDP (puerto 3389) a Internet. Nunca. Usa Tailscale, WireGuard, Cloudflare Tunnel, VPN corporativa.
✓
Gestor de passes compartido (equipo): Bitwarden Organizations, 1Password Business. Compartes acceso SIN revelar la pass. Revocas en 1 click al salir alguien.

🌐 7. Navegación segura e higiene digital

✓
Bloqueador de anuncios/rastreadores: uBlock Origin (gratis, open source, el mejor). Menos malvertising, menos tracking, web más rápida.
✓
DNS seguro: NextDNS, Cloudflare 1.1.1.1 for Families, Quad9. Bloquea dominios maliciosos, phishing, malware, telemetría a nivel red (funciona en todo el dispositivo/red).
✓
HTTPS en todas partes: Navegador fuerza HTTPS. Si web no tiene candado → no pongas datos sensibles.
✓
Extensiones mínimo y de confianza: Cada extensión es superficie de ataque. Revisa permisos. Elimina las que no usas.
✓
Wi-Fi público: Evita banca/trabajo sensible. Si obligatorio → VPN de confianza (Mullvad, Proton, IVPN, o la tuya propia).

📋 Checklist rápida mensual (15 min)

  1. Revisa haveibeenpwned → cambia passes filtradas.
  2. Verifica 2FA activo en cuentas críticas (email, banca, admin, gestor passes).
  3. Windows Update + reinicio pendiente → aplica.
  4. Prueba restaurar 1 archivo del backup → confirma que funciona.
  5. Revisa accesos de equipo: ¿alguien salió? ¿cambió rol? Revoca/ajusta.
  6. Limpia extensiones navegador / apps móvil que no usas.

🆘 ¿Te hackearon? Qué hacer YA

  1. Desconecta de red (Wi-Fi off, cable out). Evita propagación/exfiltración.
  2. Cambia passes desde dispositivo LIMPIO (móvil, otra PC). Email primero → luego banca → luego resto. Activa 2FA si no estaba.
  3. Escanea con Windows Defender (offline scan) + Malwarebytes Free.
  4. Revisa reglas de reenvío en email (configuración → reenvío/POP/IMAP). Los atacantes ponen forward a su correo.
  5. Notifica a afectados (clientes, banco, plataforma). Transparencia = confianza.
  6. Restaura de backup limpio (anterior al compromiso).
  7. Denuncia: Policía Cibernética (México: 088 / @PoliciaCibernetica), fiscalía, plataforma.
