⌨️ Los 10 atajos que cambian el juego

Memoriza estos y verás la diferencia desde el día 1. Los agrupo por categoría para que sea más fácil.

📋 Básicos universales (funcionan en todo Windows)

Ctrl + C
Copiar — Selección actual al portapapeles.
Ctrl + V
Pegar — Inserta lo copiado. Tip: Ctrl + Alt + V → Pegado especial (solo valores, formatos, fórmulas).
Ctrl + Z
Deshacer — Tu salvavidas. Funciona en cascada: vuelve atrás paso a paso.
Ctrl + Y
Rehacer — Adelanta lo deshecho. Pareja de Ctrl+Z.

🔍 Navegación y selección ninja

Ctrl + Flechas
Saltar al borde — Salta a la última celda con datos en esa dirección. Cruza regiones vacías de golpe.
Ctrl + Shift + Flechas
Seleccionar región — Selecciona desde la celda actual hasta el borde de datos. El atajo #1 para seleccionar tablas enteras al instante.
Ctrl + A
Seleccionar todo — Una vez = región actual. Dos veces = hoja completa.
Ctrl + Home / End
Ir a A1 / Última celda usada — Navegación instantánea a los extremos.
Ctrl + Page Up / Page Down
Cambiar hoja — Navega entre pestañas sin ratón.

🛠️ Edición y fórmulas

F2
Editar celda activa — Cursor dentro de la celda para modificar fórmula/texto sin doble-clic. Imprescindible.
Ctrl + (acento grave)
Mostrar/ocultar fórmulas — Ve todas las fórmulas de la hoja al instante. Ideal para auditar.
Alt + =
AutoSuma — Inserta =SUMA() adivinando el rango. Funciona en fila o columna.
F4
Repetir última acción / Referencias absolutas — En edición de fórmula: cicla A1 → → A → . Fuera: repite formato, borrado, inserción.
Ctrl + Enter
Rellenar selección — Escribe en celda activa, selecciona rango, Ctrl+Enter: pone lo mismo en TODAS las celdas seleccionadas.

🎯 Datos y tablas (productividad pura)

Ctrl + T
Crear Tabla — Convierte rango en Tabla Excel (formato, filtros, referencias estructuradas, expansión auto). Haz esto SIEMPRE.
Ctrl + Shift + L
Activar/desactivar Filtros — Pone/quita flechitas de filtro en encabezados. Funciona en tabla o rango normal.
Ctrl + F
Buscar — Panel buscar. Tip: Ctrl + H = Buscar y reemplazar.
Alt + Flecha Abajo
Abrir filtro / lista validación — En celda con filtro o validación de datos, abre el menú sin ratón.

📐 Formato y vista

Ctrl + 1
Formato de celdas — El panel completo: número, alineación, fuente, borde, relleno, protección.
Ctrl + Shift + $ / % / # / @ / !
Formatos rápidos — Moneda, porcentaje, fecha, hora, número con separador de miles.
Alt + W + F + F
Congelar paneles — Secuencia: Alt → W → F → F. Congela fila superior y/o primera columna. Imprescindible en tablas grandes.
Ctrl + Shift + "+" / "-"
Insertar / Eliminar celdas/filas/columnas — Selecciona fila/columna primero. El diálogo pregunta qué desplazar.

💡 Combos de poder (flujos reales)

Limpiar datos rápido

Ctrl + A → Ctrl + T (tabla) → Ctrl + Shift + L (filtros) → filtra vacíos/duplicados → Ctrl + - (eliminar filas) → Ctrl + Shift + L (quitar filtros).

Auditar fórmulas

Ctrl + (ver fórmulas) → Ctrl + Flechas (navegar) → F2 (editar) → F4 (fijar referencias) → Enter.

Sumar y bajar

En celda bajo columna: Alt + = (AutoSuma) → Enter → Ctrl + Flecha Abajo (saltar al siguiente bloque).

🎁 Trucos extra que valen oro

  • Doble clic en borde de celda = Ctrl + Flecha (salto al borde).
  • Arrastar con botón derecho → suelta → menú: "Copiar solo valores", "Copiar formato", "Rellenar serie".
  • Ctrl + Click en pestaña hoja = seleccionar múltiples hojas (editar todas a la vez). Cuidado: ¡afecta a todas!
  • Alt + Enter en celda = salto de línea dentro de la celda.
  • Ctrl + Shift + : = hora actual. Ctrl + ; = fecha actual. Estáticos (no cambian).
  • F11 = gráfico instantáneo en hoja nueva. Alt + F1 = gráfico en misma hoja.
