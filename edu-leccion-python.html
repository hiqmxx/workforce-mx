🐍 Qué es Python (y por qué a ti te importa)

Python es un lenguaje de programación legible, potente y con librerías para todo. Se escribe casi como inglés y hace el trabajo pesado por ti.

  • Sintaxis limpia: indentación en vez de llaves, se lee como pseudocódigo.
  • Ecosistema brutal: pandas (datos/Excel), openpyxl (Excel nativo), requests (web), smtplib (email), selenium/playwright (navegador real), beautifulsoup (scraping), schedule (tareas programadas).
  • Corre en todo lado: Windows, Mac, Linux, servidores, contenedores, la nube.
  • Gratis y open source: sin licencias, comunidad enorme, miles de tutoriales.

La mentalidad correcta

No aprendas Python "por si acaso". Aprende a resolver TU problema: "Tardo 2 horas copiando datos de 20 Excels a uno maestro" → script de 15 min → ahorras 2 horas/semana = 100 horas/año. Eso es ROI real.

🛠️ Instalación rápida (Windows)

  1. Ve a python.org/downloads → Descarga instalador Windows (64-bit).
  2. MUY IMPORTANTE: Marca ☑ Add Python to PATH antes de instalar.
  3. Instala → Abre PowerShell/CMD → escribe python --version → debe salir versión (ej. 3.12.x).
  4. Editor: VS Code (gratis, mejor experiencia) + extensión Python de Microsoft. O PyCharm Community.

📊 Caso 1: Leer y escribir Excel (pandas + openpyxl)

El 80% de automatización de oficina es "juntar Excels, limpiar, sacar reporte".

import pandas as pd

# 1. Leer múltiples archivos de una carpeta
archivos = ['ventas_ene.xlsx', 'ventas_feb.xlsx', 'ventas_mar.xlsx']
dfs = [pd.read_excel(a) for a in archivos]
todo = pd.concat(dfs, ignore_index=True)

# 2. Limpiar: quitar duplicados, nulos, estandarizar
todo = todo.drop_duplicates()
todo['fecha'] = pd.to_datetime(todo['fecha'], errors='coerce')
todo['cliente'] = todo['cliente'].str.strip().str.title()

# 3. Agrupar y resumir
resumen = todo.groupby(['cliente', 'producto']).agg(
    total_ventas=('importe', 'sum'),
    num_pedidos=('pedido_id', 'count')
).reset_index()

# 4. Exportar a Excel con formato
with pd.ExcelWriter('reporte_consolidado.xlsx', engine='openpyxl') as writer:
    resumen.to_excel(writer, sheet_name='Resumen', index=False)
    todo.to_excel(writer, sheet_name='Detalle', index=False)

print('✅ Reporte generado: reporte_consolidado.xlsx')

Tip pro

Usa pd.read_excel(..., dtype={'columna': str}) para forzar texto y evitar que pandas convierta códigos con ceros a la izquierda (ej. 00123 → 123).

📧 Caso 2: Enviar emails automáticos (smtplib + email)

Envía reportes, alertas, recordatorios. Usa contraseña de aplicación (no tu pass principal) en Gmail/Outlook.

import smtplib
from email.message import EmailMessage
import os
from dotenv import load_dotenv

load_dotenv()  # Lee .env con EMAIL_USER, EMAIL_PASS

def enviar_email(destino, asunto, cuerpo, adjunto_path=None):
    msg = EmailMessage()
    msg['Subject'] = asunto
    msg['From'] = os.getenv('EMAIL_USER')
    msg['To'] = destino
    msg.set_content(cuerpo)

    if adjunto_path:
        with open(adjunto_path, 'rb') as f:
            msg.add_attachment(f.read(), maintype='application',
                               subtype='vnd.openxmlformats-officedocument.spreadsheetml.sheet',
                               filename=os.path.basename(adjunto_path))

    with smtplib.SMTP_SSL('smtp.gmail.com', 465) as smtp:
        smtp.login(os.getenv('EMAIL_USER'), os.getenv('EMAIL_PASS'))
        smtp.send_message(msg)
    print(f'📧 Enviado a {destino}')

# Uso
enviar_email(
    'jefe@empresa.com',
    'Reporte semanal ventas',
    'Hola, adjunto el reporte consolidado de esta semana.',
    'reporte_consolidado.xlsx'
)

🌐 Caso 3: Web scraping básico (requests + BeautifulSoup)

Extrae datos de webs públicas: precios, catálogos, noticias, tablas. Respeta robots.txt y términos de uso.

import requests
from bs4 import BeautifulSoup
import pandas as pd

url = 'https://ejemplo.com/productos'
headers = {'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36'}

resp = requests.get(url, headers=headers, timeout=10)
resp.raise_for_status()

soup = BeautifulSoup(resp.text, 'lxml')

productos = []
for item in soup.select('.producto-card'):
    nombre = item.select_one('.nombre').get_text(strip=True)
    precio = item.select_one('.precio').get_text(strip=True)
    stock = item.select_one('.stock').get_text(strip=True)
    productos.append({'nombre': nombre, 'precio': precio, 'stock': stock})

df = pd.DataFrame(productos)
df.to_excel('productos_scrapeados.xlsx', index=False)
print(f'✅ {len(df)} productos guardados')

Cuándo usar Selenium/Playwright

Si la web carga datos con JavaScript (React, Vue, SPA), requests no ve el contenido renderizado. Ahí usa playwright (más rápido y fiable que Selenium hoy).

En producción: Task Scheduler de Windows

No dejes consola abierta. Crea tarea programada:
Acción: python.exe
Argumentos: C:\ruta\script.py
Iniciar en: C:\ruta\
Trigger: Diario, Semanal, Al iniciar sesión, etc. Corre en segundo plano, sin ventana.

🎯 Script completo de ejemplo: "Consolida y avisa"

Este script une todo: lee Excels de carpeta → consolida → guarda reporte → email al jefe. Cópialo, adapta rutas y credenciales, úsalo.

#!/usr/bin/env python3
# consolida_ventas.py — Ejecuta: python consolida_ventas.py
import os, glob, pandas as pd, smtplib
from email.message import EmailMessage
from dotenv import load_dotenv

load_dotenv()
CARPETA_DATOS = r'C:\Users\TuUsuario\Documents\Ventas_Mensuales'
REPORTE_SALIDA = 'reporte_ventas_consolidado.xlsx'
EMAIL_DESTINO = 'director@empresa.com'

def main():
    print('🔄 Buscando archivos...')
    archivos = glob.glob(os.path.join(CARPETA_DATOS, '*.xlsx'))
    if not archivos:
        print('❌ No hay .xlsx en la carpeta')
        return

    print(f'📂 Encontrados {len(archivos)} archivos')
    dfs = []
    for a in archivos:
        try:
            df = pd.read_excel(a)
            df['archivo_origen'] = os.path.basename(a)
            dfs.append(df)
        except Exception as e:
            print(f'⚠️ Error leyendo {a}: {e}')

    todo = pd.concat(dfs, ignore_index=True)
    todo = todo.drop_duplicates()
    todo['fecha'] = pd.to_datetime(todo['fecha'], errors='coerce')

    # Resumen por vendedor y mes
    todo['mes'] = todo['fecha'].dt.to_period('M')
    resumen = todo.groupby(['vendedor', 'mes']).agg(
        total=('importe', 'sum'),
        pedidos=('pedido_id', 'count')
    ).reset_index()

    # Guardar Excel con 2 hojas
    with pd.ExcelWriter(REPORTE_SALIDA, engine='openpyxl') as w:
        resumen.to_excel(w, sheet_name='Resumen', index=False)
        todo.to_excel(w, sheet_name='Detalle', index=False)

    print(f'✅ Reporte guardado: {REPORTE_SALIDA}')

    # Email
    enviar_email(EMAIL_DESTINO, 'Reporte consolidado ventas',
                 'Adjunto reporte automático generado hoy.', REPORTE_SALIDA)

def enviar_email(to, subject, body, attachment):
    msg = EmailMessage()
    msg['Subject'], msg['From'], msg['To'] = subject, os.getenv('EMAIL_USER'), to
    msg.set_content(body)
    with open(attachment, 'rb') as f:
        msg.add_attachment(f.read(), maintype='application',
                           subtype='vnd.openxmlformats-officedocument.spreadsheetml.sheet',
                           filename=os.path.basename(attachment))
    with smtplib.SMTP_SSL('smtp.gmail.com', 465) as s:
        s.login(os.getenv('EMAIL_USER'), os.getenv('EMAIL_PASS'))
        s.send_message(msg)
    print('📧 Email enviado')

if __name__ == '__main__':
    main()
