Web scraping ético
con Python

Extrae información pública de la web de forma responsable y técnica. Aprende a usar requests y BeautifulSoup, respetar límites, y saber cuándo es mejor usar una API oficial.

Qué es scraping y cuándo es apropiado

El web scraping es la extracción automatizada de información desde páginas web. Puede ser útil para investigación, monitoreo de precios propios, agregación de datos públicos o migraciones. Sin embargo, no todo lo técnicamente posible es apropiado: debes considerar términos de servicio, derechos de autor, datos personales y carga sobre los servidores.

Antes de escribir código, pregunta: ¿existe una API oficial o un dataset descargable? Las APIs son más estables, legales y eficientes. Si no hay alternativa, revisa el archivo robots.txt del sitio, los términos de uso y limita la frecuencia de tus solicitudes.

Principios de scraping ético

Identifícate con un User-Agent claro, respeta robots.txt y los términos del sitio, no recolectes datos personales sin base legal, evita sobrecargar servidores (rate limiting, horarios razonables) y usa los datos conforme a la normativa aplicable.

HTML, DOM y cómo encontrar datos

Las páginas web son documentos HTML estructurados en un árbol (DOM). Para extraer datos necesitas localizar elementos por etiquetas, clases, ids o atributos. Las herramientas de desarrollador del navegador (F12 → Elements/Inspector) te permiten inspeccionar la estructura y probar selectores.

<article class="product">
  <h2 class="title">Teclado mecánico</h2>
  <span class="price" data-currency="MXN">899.00</span>
  <a href="/p/teclado-123">Ver detalle</a>
</article>

En este ejemplo puedes seleccionar por clase (.product, .price), etiqueta (h2, a) o atributo ([data-currency]). CSS selectors y métodos de búsqueda del parser son la base del scraping estático.

requests + BeautifulSoup: flujo básico

Para páginas HTML estáticas, la combinación estándar en Python es requests (descarga) y beautifulsoup4 (parseo). Instala dependencias y prueba un flujo mínimo:

pip install requests beautifulsoup4 lxml
import time
import requests
from bs4 import BeautifulSoup

url = "https://example.com/productos"
headers = {
    "User-Agent": "MiBotEducativo/1.0 (contacto@ejemplo.com)"
}

resp = requests.get(url, headers=headers, timeout=15)
resp.raise_for_status()  # lanza error si no es 2xx

soup = BeautifulSoup(resp.text, "lxml")
for card in soup.select("article.product"):
    title = card.select_one(".title").get_text(strip=True)
    price = card.select_one(".price").get_text(strip=True)
    link = card.select_one("a")["href"]
    print(title, price, link)

time.sleep(1.5)  # pausa entre solicitudes

Usa timeout siempre para evitar bloqueos, maneja excepciones (RequestException) y valida que los elementos existan antes de acceder a atributos. Las estructuras de las páginas cambian: escribe código defensivo.

robots.txt, límites y robustez

El archivo robots.txt (p. ej. https://sitio.com/robots.txt) indica rutas permitidas o desaconsejadas para crawlers. Respétalo como norma de buena ciudadanía web. Además, implementa límites en tu cliente:

  • Inserta demoras (time.sleep) o usa rate limiters para no saturar.
  • Reintenta con backoff exponencial ante errores temporales (429, 503).
  • Cachea respuestas durante desarrollo para no repetir descargas.
  • Registra URLs y códigos de estado para auditoría.
  • No evadas barreras técnicas de acceso ni controles anti-bot de sitios que prohíben scraping.

Páginas dinámicas

Si el contenido se genera con JavaScript en el cliente, requests no verá los datos renderizados. En esos casos evalúa primero si hay una API interna (pestaña Network en DevTools) o usa herramientas de automatización de navegador (Playwright/Selenium) con las mismas consideraciones éticas y legales.

Almacenar y limpiar datos

Extraer es solo la mitad: los datos deben guardarse de forma utilizable. Para conjuntos pequeños, CSV o JSON suelen bastar; para procesos recurrentes, considera una base de datos.

import csv

rows = [{"title": "Teclado", "price": "899.00"},
        {"title": "Mouse", "price": "299.00"}]

with open("productos.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=["title", "price"])
    writer.writeheader()
    writer.writerows(rows)

Limpia espacios, normaliza monedas/fechas y deduplica registros. Si el proyecto crece, pandas facilita transformación y validación antes de cargar a tu destino final.

Checklist práctico

  • ¿Hay API o feed oficial? Prefiérelo.
  • ¿Revisaste robots.txt y términos de uso?
  • ¿Tu User-Agent identifica el propósito y contacto?
  • ¿Tienes timeouts, manejo de errores y límites de tasa?
  • ¿Evitas datos personales y cumples normativa?
  • ¿El scraper es resiliente a cambios menores de HTML?

El scraping responsable combina técnica y criterio. Un extractor bien diseñado es respetuoso, mantenible y produce datos limpios que realmente puedes usar.
