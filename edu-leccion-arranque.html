¿Qué pasa cuando
enciendes tu PC?

Aprietas el botón y... magia. En 4 pasos entiendes qué ocurre entre el click y tu escritorio. Sin misterios.

🔄 La secuencia completa en 4 pasos

Cada vez que enciendes, tu PC sigue un ritual preciso. Conocerlo te ayuda a diagnosticar problemas y entender por qué a veces "no arranca".

1

⚡ Paso 1: Recibe energía (Power On)

Aprietas el botón → la fuente de poder (PSU) envía corriente a la placa base. El chip controlador de gestión de energía (a menudo un microcontrolador aparte) "despierta" y empieza a distribuir voltajes estables (3.3V, 5V, 12V) a cada componente.

Lo que ves: Ventiladores giran, LEDs se encienden. Si no pasa esto: revisa cable de poder, interruptor PSU, toma de corriente, o que la PSU no haya muerto.

2

🔍 Paso 2: POST — Power-On Self Test

El firmware de la placa base (BIOS o UEFI) ejecuta una autoprueba. Verifica: CPU presente y funcional, RAM detectada y usable, GPU (integrada o dedicada) responde, almacenamiento conectado, teclado/ratón.

Si todo OK: beep único (o logo del fabricante). Si falla: códigos de beep o LED de diagnóstico (DRAM, CPU, VGA, BOOT) indican qué falla. Sin RAM = beeps continuos. Sin GPU = beeps patrón específico.

UEFI vs BIOS legacy

UEFI = moderno, interfaz gráfica, arranque seguro (Secure Boot), soporta discos >2TB, más rápido. BIOS = antiguo, texto, límites de 2TB. Hoy todo es UEFI.

3

💾 Paso 3: Carga el gestor de arranque → Kernel de Windows

UEFI busca el gestor de arranque en la partición EFI del disco (ESP). En Windows: bootmgfw.efi. Este carga winload.efi que a su vez carga el kernel de Windows (ntoskrnl.exe) en memoria, junto con drivers críticos (sistema de archivos, almacenamiento, bus).

Luego inicia Session Manager (smss.exe) que prepara el entorno de usuario: crea sesiones, carga registry, inicia subsistema Win32. Ves la pantalla con el logo de Windows y los puntitos girando.

4

👤 Paso 4: Inicio de sesión (Logon)

Windows lanza LogonUI (pantalla de login). Introduces PIN, contraseña, huella o Face ID (Windows Hello). El sistema valida credenciales contra SAM (local) o Active Directory / Azure AD (empresa).

Si OK: carga tu perfil de usuario (NTUSER.DAT, carpetas Escritorio, Documentos, etc.), inicia Explorer.exe (barra de tareas, menú Inicio, escritorio) y tus apps de inicio. ¡Ya estás en el escritorio!

⚙️ Entrar a BIOS/UEFI: la tecla mágica

Arranca y machaca la tecla antes de que salga el logo de Windows:

  • F2: ASUS, Acer, Dell, Lenovo, Samsung, Sony
  • Delete / Supr: MSI, Gigabyte, ASRock, muchas placas base
  • F10: HP, algunas Compaq
  • F1: Lenovo ThinkPad, algunos Toshiba
  • Esc: Algunas HP, menú de arranque temporal

Desde Windows (si arranca)

Configuración → Sistema → Recuperación → Inicio avanzado → Reiniciar ahora → Solucionar problemas → Opciones avanzadas → Configuración de firmware UEFI → Reiniciar. Entra directo a UEFI.

🚀 Arranque rápido (Fast Startup) — ¿activado o no?

Windows guarda el estado del kernel en disco al apagar (hibernación híbrida). Al encender, lo restaura en vez de cargar desde cero. Más rápido, pero puede causar problemas con dual-boot, actualizaciones de drivers, o si cambias hardware.

Desactivar: Panel de control → Opciones de energía → Elegir comportamiento del botón de inicio → Cambiar configuración no disponible → Desmarca "Activar inicio rápido".
