📊 Qué es un dashboard (y qué NO es)

Un dashboard es una pantalla única que muestra tus métricas clave (KPIs) de forma visual, actualizada y accionable. No es un reporte de 20 páginas, no es un Excel con 50 pestañas, no es "datos bonitos sin contexto".

  • Una vista: todo cabe en una pantalla (scroll mínimo).
  • Tiempo real / cerca: datos frescos (hoy, esta semana, mes actual).
  • Accionable: cada número responde a \"¿qué hago con esto?\".
  • Comparativo: actual vs meta, vs mes anterior, vs año anterior.

Analogía del coche

Tu dashboard = tablero del coche. Velocímetro (ventas), nivel gasolina (caja), temperatura (margen), check engine (alertas). No necesitas saber RPM del motor, inyección, presión aceite. Solo lo que te evita accidente o multa.

🎯 KPIs esenciales de ventas (los que importan)

No midas todo. Mide lo que mueve la aguja. Estos 6 cubren 90% de necesidades PyME.

1. Ventas netas (Revenue) — \"¿Cuánto entró?\"

Facturado - devoluciones - descuentos. Meta mensual vs real. Tendencia 12 meses. Desglose: por vendedor, canal, producto, región.

2. Ticket promedio — \"¿Cuánto gasta cada cliente?\"

Ventas netas / # transacciones. Subirlo = más rentable sin más clientes. Cruzventa, upsell, paquetes.

3. Tasa de conversión — \"¿Cuántos prospectos cierran?\"

Ventas ganadas / Oportunidades creadas. Por vendedor, canal, etapa. Baja = problema en propuesta, precio, seguimiento, calidad lead.

4. Ciclo de venta (días) — \"¿Qué tan rápido cerramos?\"

Fecha primer contacto → fecha cierre. Promedio y mediana. Largo = capital de trabajo atrapado, riesgo de perder deal.

5. CAC (Costo de adquisición cliente) — \"¿Cuánto cuesta traer uno?\"

Gasto marketing+ventas mes / clientes nuevos mes. Debe ser < LTV (valor vida cliente). Si CAC > LTV = pierdes dinero por cliente.

6. Margen de contribución — \"¿Qué queda tras costos variables?\"

(Ventas - Costos variables) / Ventas %. Paga fijos y genera utilidad. Por producto/cliente/canal te dice dónde enfocar.

💰 KPIs de gastos y salud financiera

Vender mucho sin controlar gasto = trabajar gratis. Estos 4 te cuidan la caja.

Gastos operativos totales (OpEx)

Nómina, renta, servicios, marketing, software, viajes. % vs ventas. Tendencia mes a mes.

Flujo de caja (Cash Flow)

Entradas reales (cobros) - Salidas reales (pagos). No facturación, cobro. Proyección 4-8 semanas.

Cuentas por cobrar (Días promedio / Antigüedad)

¿Cuánto tardan en pagarte? > 45-60 días = alerta. Top 5 deudores. % vencido > 90 días.

Utilidad neta / EBITDA

Lo que realmente ganas. Última línea. Si ventas suben pero utilidad baja = revisa costos/margen.

Regla visual

Máximo 6-8 widgets por dashboard. Uno principal (KPI card grande), 3-4 secundarios (barras/línea), 1-2 de detalle (tabla). Blanco = respira. Colores: verde=bueno, rojo=malo, amarillo=atención, azul=neutro. Consistencia siempre.

🧠 Tomar decisiones con datos (no corazonadas)

El dashboard no decide por ti. Te da la evidencia. Tú decides. Flujo:

  1. Observa: \"Ventas bajaron 15% vs mes anterior\".
  2. Segmenta: \"Es solo canal online. Tienda y mayoreo estables\".
  3. Profundiza: \"Tráfico web igual, conversión cayó de 3.2% a 2.1%\".
  4. Hipotetiza: \"Cambiamos checkout la semana pasada → fricción nueva\".
  5. Actúa: \"Revertir cambio / A/B test / arreglar bug\".
  6. Mide: \"Semana siguiente conversión vuelve a 3% → fixed\".

Preguntas que tu dashboard debe responder

  • ¿Vamos a cumplir la meta este mes? (Sí/No/Al límite)
  • ¿Qué vendedor/producto/canal está fallando?
  • ¿Hay algún cliente grande en riesgo (no compra hace 60 días)?
  • ¿Tenemos caja para nómina y proveedores próximas 4 semanas?
  • ¿Dónde invertir el próximo peso de marketing para mayor retorno?

🛠️ Herramientas simples (elige tu nivel)

🟢 Nivel 1: Excel / Google Sheets (Gratis, ya lo tienes)

Tablas dinámicas + Gráficos + Segmentadores + Formato condicional = dashboard funcional. Conecta a CSV/BD con Power Query. Publica en OneDrive/Drive para ver en móvil. Ideal para empezar HOY.

🟡 Nivel 2: Power BI (Gratis Desktop / Pro user/mes)

Modelado DAX, actualización programada, app móvil, row-level security, 100+ conectores. Curva de aprendizaje media. Estándar empresarial Microsoft.

🟡 Nivel 2: Looker Studio / Data Studio (Gratis)

Conectores nativos Google (Sheets, Ads, Analytics, BigQuery, SQL). Compartir por link, embebible. Muy visual, menos modelado que Power BI.

🟠 Nivel 3: Metabase / Apache Superset (Open source, self-hosted)

SQL nativo, dashboards bonitos, alertas, embebido. Requiere servidor (VPS, Docker). Control total, sin costos por usuario. Para equipos técnicos.

🔴 Nivel 4: A medida (Python + Streamlit / Plotly Dash / FastAPI + React)

Lo que hacemos en WorkForce MX. Integra tu ERP, CRM, BD, APIs. Lógica de negocio real, alertas por WhatsApp/Email, multi-tenant, white-label. Escalable, tuyo para siempre.

🚀 Tu siguiente paso

  1. Define 3-5 KPIs que SI importan para TU negocio (no copies lista genérica).
  2. Identifica dónde están los datos hoy (Excel, ERP, CRM, Sheets, BD).
  3. Arma un MVP en Excel/Sheets esta semana: 1 hoja KPIs, 1 hoja gráficos.
  4. Compártelo con tu socio/gerente. Pide feedback: \"¿Esto te sirve para decidir?\".
  5. Itera. Automatiza actualización (Power Query, Apps Script, Python).
  6. Cuando Excel se quede corto → Power BI / Looker / A medida.
