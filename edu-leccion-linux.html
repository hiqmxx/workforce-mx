Linux terminal
esencial

Dominar la terminal Linux te da control preciso sobre servidores, contenedores y entornos de desarrollo. Aprende los comandos y conceptos que usarás todos los días.

Por qué la terminal

La terminal (shell) es una interfaz textual para interactuar con el sistema operativo. En servidores, contenedores Docker y entornos cloud es frecuentemente la única interfaz disponible. Bash es el shell más común, aunque existen otros como zsh. Los comandos son composables: puedes encadenar programas pequeños para resolver tareas complejas, automatizar con scripts y trabajar por SSH en máquinas remotas.

La filosofía Unix favorece herramientas que hacen una cosa bien y se conectan mediante texto. Entender esta idea te permite combinar utilidades estándar con gran potencia.

Estructura de un comando

comando [opciones] [argumentos]. Usa man comando o comando --help para ver documentación. Las rutas pueden ser absolutas (/var/log) o relativas (./scripts).

Navegación y sistema de archivos

Linux organiza todo en un árbol que comienza en /. Directorios clave: /home (usuarios), /etc (configuración), /var (logs/datos variables), /usr/bin (binarios), /tmp (temporales).

pwd                 # directorio actual
ls -lah             # lista detallada, incluye ocultos, tamaños legibles
cd /var/log         # cambia de directorio
cd ..               # sube un nivel
cd ~                # a tu home
find . -name "*.log" -type f
tree -L 2           # vista de árbol (si está instalado)

Los archivos ocultos comienzan con punto (.bashrc). Usa tabulación para autocompletar rutas y evitar errores.

Crear, copiar, mover y ver archivos

touch notas.txt                 # crea archivo vacío
mkdir -p proyectos/app/logs     # crea directorios anidados
cp origen.txt copia.txt         # copia
cp -r carpeta destino/          # copia recursiva
mv viejo.txt nuevo.txt          # mueve/renombra
rm archivo.txt                  # elimina (¡sin papelera!)
rm -r carpeta/                  # elimina directorio recursivamente
cat archivo.txt                 # muestra contenido
less archivo.txt                # visor paginado (q para salir)
head -n 20 archivo.txt
tail -n 50 -f /var/log/syslog  # sigue el archivo en vivo

Ten extremo cuidado con rm -rf: borra sin confirmación. Verifica la ruta con pwd y ls antes de eliminar.

Permisos y propiedad

Cada archivo tiene permisos para usuario (u), grupo (g) y otros (o): lectura (r), escritura (w), ejecución (x). ls -l muestra algo como -rwxr-xr--.

chmod u+x script.sh        # agrega ejecución al propietario
chmod 644 archivo.txt      # rw-r--r--
chmod 755 carpeta/         # rwxr-xr-x
chown usuario:grupo archivo
sudo comando               # ejecuta como superusuario (con precaución)

Los permisos protegen el sistema multiusuario. Evita usar 777 como solución rápida; concede el mínimo privilegio necesario. Los scripts necesitan permiso de ejecución y un shebang (#!/bin/bash).

Usuarios y sudo

sudo eleva privilegios temporalmente según la política del sistema. Úsalo solo cuando la tarea lo requiera (instalar paquetes, editar configuración en /etc, gestionar servicios).

Procesos, paquetes y servicios

ps aux                     # procesos en ejecución
top                        # monitor interactivo (o htop)
kill -15 <PID>             # termina educadamente
kill -9 <PID>              # fuerza terminación

# Paquetes (Debian/Ubuntu)
sudo apt update
sudo apt install nginx

# Servicios (systemd)
sudo systemctl status nginx
sudo systemctl start nginx
sudo systemctl enable nginx

En distribuciones basadas en Red Hat/Fedora se usa dnf o yum. Conocer el gestor de paquetes de tu distro es esencial para administrar software y actualizaciones de seguridad.

Pipes, redirección y búsqueda de texto

La potencia de la terminal surge al conectar comandos: la salida de uno alimenta la entrada del siguiente con el pipe |.

grep "ERROR" app.log                 # busca líneas con patrón
grep -RIn "TODO" src/                # recursivo, con número de línea
cat access.log | grep 404 | wc -l    # cuenta coincidencias
sort datos.txt | uniq -c | sort -nr  # frecuencias ordenadas
command > salida.txt                 # redirige stdout (sobrescribe)
command >> salida.txt                # anexa
command 2> errores.txt               # stderr

Herramientas como awk, sed, cut y xargs permiten transformar texto estructurado. Estas habilidades son directamente útiles para analizar logs, procesar CSVs y automatizar tareas en servidores y contenedores.

Red y acceso remoto

ip addr                 # interfaces y direcciones
ping -c 4 8.8.8.8       # conectividad
curl -I https://ejemplo.com
ss -tulpn               # puertos en escucha
ssh usuario@servidor    # acceso remoto seguro
scp archivo user@host:/ruta/

SSH es la base de la administración remota. Usa llaves en lugar de contraseñas cuando sea posible y restringe accesos. Estas herramientas se combinan con Docker y la nube en flujos reales de operación.

Si te interesa esto, también mira

  • Docker y contenedores básicos — Linux es la base de la mayoría de contenedores.
  • Scripts y automatización — convierte comandos en scripts reutilizables.
  • Cloud básico: AWS / Azure / GCP — administra servidores en la nube.
